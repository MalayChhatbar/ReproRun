# Recipes

These recipes are intentionally copy-paste-oriented. They show how to use the current CLI on common real-world cases.

- [flaky-pytest.md](flaky-pytest.md): isolate flaky Python tests and rerun them deterministically
- [node-vitest.md](node-vitest.md): run a Vitest target with fixed env and file inputs
- [rust-cargo-test.md](rust-cargo-test.md): wrap a Rust test target and compare runs
- [github-actions.md](github-actions.md): use ReproRun inside CI
- [cache-debugging.md](cache-debugging.md): inspect and diff cached artifacts when a cache key looks wrong
